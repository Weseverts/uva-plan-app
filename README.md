# UVA Plan Data Entry

Offline field app for collecting Vermont Use Value Appraisal (Current Use) forest management plan data: stands, field notes, per-stand checklists, field map with GPS check-ins, and cruise plot layout.

Open the GitHub Pages address on a phone or tablet and install it ("Add to home screen" / "Install app"). After the first load it works with no signal. Property data stays on the device until you save or share the data file.

Bump `VERSION` in `sw.js` with every change so installed copies pick up the update.
